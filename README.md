# gh-pages: the vocabulary page

This branch holds one generated page, published at
https://mathdb-lean.github.io/problems/. It shows which Mathlib definitions the
statements on `main` are written in, the problem groups and statement shapes that
follow from them, and the implications Lean proved between pairs of statements.

`index.html` is generated by the mathdb-lean library's `tools/vocabulary.py` and
`tools/relations.py` from `main` at the commit the page names. Do not edit it by
hand; regenerate it and replace it. Nothing on `main` reads this branch.
