# Additional MathDB statement sources

These files preserve the exact bytes of statements already attached to MathDB problems outside the released benchmark. Folders use the production MathDB problem number: `https://mathdb.com/p/<number>`.

`manifest.json` records each source hash and its original provenance. The Sun Prize candidates were compiled before their existing development import; inclusion here does not certify their mathematical scope or mark them as reviewed. The demo statement is not a payable prize.

These files are not additional benchmark tasks and do not use the repository's current benchmark environment. MathDB keeps the original target, toolchain, dependency pins, and verification records unchanged. Publishing a numeric public link does not upgrade or re-import a target.
